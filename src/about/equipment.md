# My Gear

The hardware and software tools I use for daily development and blogging.

## Hardware

| Device   | Model / Specs                       | Notes                                 |
|----------|-------------------------------------|---------------------------------------|
| Laptop   | MacBook Pro 14 (M3 Pro, 18G + 512G) | Main dev machine                      |
| Monitor  | 27" 4K Monitor                      | External display, dual-screen setup   |
| Keyboard | Keychron K2                         | Mechanical keyboard, great for coding |
| Mouse    | Logitech MX Master 3S               | Ergonomic, multi-device switching     |
| Earbuds  | AirPods Pro 2                       | Noise cancelling for focus            |

## Dev Tools

- **Editor**: [VS Code](https://code.visualstudio.com/) + [JetBrains](https://www.jetbrains.com/) (IDEA, WebStorm)
- **Terminal**: iTerm2 + Oh My Zsh
- **Git GUI**: [GitKraken](https://www.gitkraken.com/) / SourceTree
- **API Debugging**: [Postman](https://www.postman.com/) / [Apifox](https://apifox.com/)
- **Database**: Navicat / DataGrip
- **HTTP Proxy**: Charles

## Productivity

- **Notes**: [Obsidian](https://obsidian.md/) / Yuque, for study notes
- **Markdown Editor**: Typora
- **Screenshot**: [Snipaste](https://www.snipaste.com/) / iShot
- **Video Editing**: Final Cut Pro / CapCut
- **Browser**: Chrome + [Arc](https://arc.net/)
