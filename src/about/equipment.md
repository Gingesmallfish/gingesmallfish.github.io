# 工作装备

日常开发和写博客使用的硬件设备与软件工具。

## 硬件设备

| 设备   | 型号 / 配置                         | 说明                   |
|--------|-------------------------------------|------------------------|
| 电脑   | MacBook Pro 16 (M4 Pro, 24G + 1T)   | 主力开发机             |
| 显示器 | 27 寸 4K 显示器                     | 外接屏幕，双屏办公     |
| 键盘   | Keychron K2                         | 机械键盘，敲代码很舒服 |
| 鼠标   | Logitech MX Master 3S               | 人体工学，多设备切换   |
| 耳机   | AirPods Pro 2                       | 听歌降噪，专注写代码   |

## 开发工具

- **编辑器**：[VS Code](https://code.visualstudio.com/) + [JetBrains 全家桶](https://www.jetbrains.com/)（IDEA、WebStorm）
- **终端**：iTerm2 + Oh My Zsh
- **Git 图形化**：[GitKraken](https://www.gitkraken.com/) / SourceTree
- **接口调试**：[Postman](https://www.postman.com/) / [Apifox](https://apifox.com/)
- **数据库**：Navicat / DataGrip
- **抓包工具**：Charles

## 效率软件

- **笔记**：[Obsidian](https://obsidian.md/) / 语雀，记录学习笔记
- **Markdown 编辑**：Typora
- **截图标注**：[Snipaste](https://www.snipaste.com/) / iShot
- **剪辑**：Final Cut Pro / 剪映
- **浏览器**：Chrome + [Arc](https://arc.net/)

以上装备仅代表个人使用习惯，大家按自己的喜好选择即可～
